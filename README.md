الفكرة الأساسية للمخزن الدائري

تخيل عندك صف طوابير فيه أماكن محددة (مثلاً 5 كراسي).
لما تجي تكتب حرف، تحطه في الكرسي اللي قدامك، وبعدين تنتقل للكرسي اللي بعده.
لما توصل لآخر كرسي، ترجع لأول كرسي (لفّ).
وكذلك لما تقرأ، تاخد الحرف من أول كرسي (tail) وبعدين تروح للكرسي اللي بعده.

· head: المؤشر اللي يحكي لك "أين نكتب المرة الجاية".
· tail: المؤشر اللي يحكي لك "أين نقرأ المرة الجاية".
· count: عدد الحروف اللي موجودة فعلًا داخل المخزن.


ليه سمّوه "دائري"؟

لأن المؤشرات تلتف حول المصفوفة باستخدام المعامل %:

يعني لو head كان عند آخر خانة (يعني size-1) وبعدين ضفنا 1، head يقلّب إلى 0 مباشرة.


كيف نعرف إذا حالة المخزن؟

· فارغ: count == 0
· ممتلى: count == size

لماذا نستخدم head == tail من أجل نعرف؟ لأن head == tail قد يعني المخزن فارغ وقد يعني المخزن ممتلى. لهذا السبب نضيف count عشان نعرف الفرق.


شو صار في الكود؟

1. أخذنا اسم المستخدم عن طريق fgets.
2. أضفنا له "CE-ESY" عشان تكون الجملة كاملة.
3. جرّبناه بحجم مخزن صغير (5): أول 5 حروف دخلت، والباقي رفضوا وظهر overflow.
4. جرّبناه بحجم مخزن كبير (طول الجملة + 10): دخلت كل الحروف عادي.
5. قرأنا الحروف ورجعناها باستخدام cb_read لحد ما count يوصل الصفر.
6. في النهاية طلعنا النص زي ما دخلنا، وتأكدنا أن المخزن صار فاضي.


أهم دالتين في الحل

// الكتابة: تحط الحرف وتحرك head وتزيد count
int cb_write(...) {Coding}

// القراءة: تاخد الحرف وتحرك tail وتنقص count
int cb_read(...) {Coding}
باختصار، آلية الحل كلها تعتمد على مؤشرين و مصفوفة مع عداد.
